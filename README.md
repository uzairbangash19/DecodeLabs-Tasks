This repository contains my submissions for the DecodeLabs Cyber Security Industrial Training Kit.

## Tasks

### Task 1: Password Strength Checker
Python script that checks a password's length, uppercase letters, numbers, and symbols, then rates it Weak, Medium, or Strong.
- File: `password strength checker.py`

### Task 2: Caesar Cipher Encryption & Decryption
Python script that encrypts and decrypts text using the Caesar cipher with a user-defined shift value.
- File: `caesar cipher.py`

### Task 3: Phishing Awareness Analysis
Analysis of sample phishing emails, listing red flags and explaining why each is unsafe. Includes a bonus red-flag checklist.
- File: `phishing awareness analysis.md`

### Task 4: System Vulnerability Checklist (Optional)
Checklist for auditing a system's security — passwords/MFA, software updates, and unsafe user practices — with risk ratings.
- File: `system vulnerability checklist.md`
